# **PXA Engine \- 像素动画工具 (Pixel Animation Tool)**

PXA Engine 是一个专注于像素艺术创作的轻量级、高性能 2D 引擎与编辑工具。项目基于 Rust 和 wgpu 构建，目前不仅提供了稳定且功能丰富的像素绘画模块，还搭载了支持硬件加速的 2D 骨骼动画系统。

## **✨ 核心特性**

### **🚀 全新视口与渲染引擎 (New\!)**

* **无限画布与平移缩放：** 底层坐标系全面升级（支持 i32 负坐标），允许在画布外自由平移、绘制和选区操作。  
* **像素级精准映射：** 彻底解决高分屏 (HiDPI) 缩放导致的偏移问题，实现屏幕物理坐标与逻辑画布的 1:1 完美映射，“指哪画哪”。  
* **局部脏矩形渲染 (Dirty Rect)：** 针对画笔和工具操作进行了极高的性能优化，仅重绘变动区域，保持丝滑帧率。

### **🎨 像素绘画与图像编辑**

* **基础工具链：** 铅笔、橡皮、智能油漆桶（支持选区边界）、取色器、选区（矩形/椭圆，支持布尔运算）。  
* **高级钢笔工具：** 贝塞尔 (Bézier) 曲线绘制、节点调节、路径转选区/填充/描边。  
* **对称绘制：** 支持水平、垂直、四象限、平移对称，支持自定义拖拽对称轴。  
* **图层系统：** 支持无限图层、新建/删除/复制/向下合并、不透明度调节、多种混合模式（正常、正片叠底、屏幕、线性减淡等）、图层锁定。  
* **调色板管理：** 内置 PICO-8 经典调色板，支持添加/删除自定义颜色，支持导入和导出 HEX 色板文件。

### **🦴 骨骼动画系统**（注意骨骼动画系统存在BUG，请小心使用，由于个人开发者，今天主要在修复导入PNG的像素画逻辑，所以无法测试到骨骼，只能说单元测试通过）

* **骨骼装配：** 可视化创建骨骼，拖拽建立父子 FK（正向运动学）层级，支持图层插槽 (Slot) 绑定。  
* **多轨道时间轴 (Dopesheet)：** \- 支持位移 (Translation)、旋转 (Rotation)、缩放 (Scale) 属性的独立 K 帧。  
  * 支持自动关键帧 (Auto-Key) 记录。  
  * 框选、拖拽、删除关键帧，支持无限撤销/重做。  
* **曲线编辑器 (Curve Editor)：** 支持关键帧之间的线性 (Linear)、阶跃 (Stepped) 和 自定义贝塞尔曲线 (Bézier) 平滑插值。  
* **循环偏移系统 (Cyclic Offset)：** 支持对选中关键帧进行时间轴拖拽偏移，或使用高级参数（固定偏移/递增偏移）实现复杂的循环随动动画（如波浪、飘带效果），引擎会自动处理循环补帧。  
* **GPU 蒙皮与渲染：** 动画预览由 wgpu 着色器进行矩阵变换计算，保证播放时的极低开销。

### **💾 工程与文件 IO**

* **PXAD 专属格式：** 自定义分块存储格式，支持版本控制与 CRC32 完整性校验，包含所有图层、调色板、选区和骨骼动画数据。  
* **灵活导出：** 支持导出 PNG 静态图、PNG 序列帧文件夹，以及 GIF 循环动画。  
* **图像处理管道：** 支持导入外部图片，内置重采样、对比度/亮度调节、智能降色 (Quantize) 与边缘暗化描边 (Selout) 算法。  
* **多语言支持 (i18n)：** 内置简体中文、繁体中文、English 等多种界面语言。

## **🛠️ 如何构建与运行**

### **环境要求**

* Rust 1.70+（[安装 Rust](https://www.rust-lang.org/tools/install)）  
* 操作系统：Windows / macOS / Linux (主要基于 Win32 与 wgpu 测试)  
* 现代 GPU（支持 Vulkan / Metal / DX12，或回退至 DX11/OpenGL）

### **构建步骤**

git clone \[https://github.com/18301724526/pxa\_engine\_win32.git\](https://github.com/18301724526/pxa\_engine\_win32.git)  
cd pxa\_engine\_win32  
cargo build \--release

### **运行**

cargo run \--release

## **📖 基本使用指南**

### **绘画模式 (Paint Mode)**

* 启动后默认进入绘画模式。  
* 使用快捷键 \[ 和 \] 调节画笔大小，P 切换铅笔，E 切换橡皮，B 切换油漆桶。  
* 使用 Ctrl \+ Z 和 Ctrl \+ Y 撤销/重做。  
* 按住 Space (空格键) 并拖拽鼠标可平移视口，滚动滚轮可缩放。

### **动画模式 (Animate Mode)**

点击顶部标题栏的 “🎞” 图标进入骨骼动画编辑：

1. **装配：** 在绘画模式下使用“骨骼”工具创建骨架，并在图层面板将图层拖拽到目标骨骼上完成绑定。  
2. **建轨：** 切换到动画模式，在底部时间轴点击“新建动画”。  
3. **K 帧：** 选中目标骨骼，使用工具栏的“移动”或“旋转”工具调整姿态，开启“自动关键帧”即可记录动画。  
4. **曲线与偏移：** 展开“显示筛选”或“曲线”，调整动画节奏；选中多帧后开启“偏移模式”拖拽，可快速制作流体跟随动画。
